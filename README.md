# 관계 해부도 · RELATION ANATOMY

두 캐릭터의 관계를 8축 점수, 8개의 상황, 관계 역학 판정으로 풀어 한 장의 포스터로 만드는 메이커 — 단일 HTML 파일.

**https://yuuuulll35.github.io/relation-anatomy/**

- OOC 프롬프트를 복사해 롤플레잉 AI에 보내고, 받은 JSON 답변을 붙여 넣으면 포스터가 채워집니다.
- 입력한 내용은 브라우저(localStorage)에만 저장됩니다.
- 완성된 포스터는 PNG 이미지로 저장할 수 있습니다.
